# v0.95 宠物内丹系统 (Pet Inner Dan System)

## 📋 概述

宠物内丹系统是梦幻西游经典养成玩法之一，玩家可以让宠物吞服内丹来获得特殊能力和属性加成。

## 🎯 核心功能

### 1. 内丹类型

**低级内丹 (1-4 级)**
- **矫健**：气血 +10%/20%/30%/40%
- **静岳**：魔法 +10%/20%/30%/40%
- **灵动**灵力 +10%/20%/30%/40%
- **坚甲**：防御 +10%/20%/30%/40%
- **迅敏**：速度 +10%/20%/30%/40%
- **暴戾**：伤害 +10%/20%/30%/40%
- **针锋**：命中 +10%/20%/30%/40%
- **御空**：**飞行单位专属**，速度 +15%/30%/45%/60%

**高级内丹 (5 层)**
- **舍身击**：牺牲气血造成额外伤害
- **阴伤**：法术连击时增加伤害
- **连环**：物理连击时增加伤害
- **神佑**：**死亡时概率复活**
- **怒击**：**首回合额外伤害**
- **洞察**：**无视部分防御**
- **吸血**：**物理攻击吸血**
- **法术连击**：**概率触发法术连击**

### 2. 内丹获取
- 剧情任务奖励
- 副本掉落
- 帮派技能炼制
- 商城购买
- 活动奖励

### 3. 内丹升级
- 吞噬相同内丹提升等级
- 使用内丹经验书
- 最高等级：4 级 (低级) / 5 层 (高级)

### 4. 内丹装备
- 每只宠物可装备 **3 个低级内丹 + 1 个高级内丹**
- 内丹可以卸下重新装备
- 内丹绑定到宠物 (可选设定)

### 5. 内丹克制
- 某些内丹之间存在协同效果
- 特定内丹组合激活套装效果

## 📊 数据结构

```typescript
interface InnerDan {
  id: string;
  name: string;
  type: 'low' | 'high'; // 低级/高级
  level: number; // 1-4 (低级) / 1-5 (高级)
  exp: number;
  effect: InnerDanEffect;
  description: string;
  icon?: string;
}

interface InnerDanEffect {
  stat?: StatType; // 属性加成类
  value?: number; // 加成百分比
  trigger?: TriggerType; // 触发类效果
  triggerChance?: number; // 触发概率
  special?: SpecialEffect; // 特殊效果
}

interface PetInnerDanSlot {
  danId: string | null;
  level: number;
  exp: number;
}

interface PetInnerDanConfig {
  lowSlots: number; // 低级内丹槽位 (3)
  highSlots: number; // 高级内丹槽位 (1)
  maxLowLevel: number; // 低级内丹最高等级 (4)
  maxHighLevel: number; // 高级内丹最高层数 (5)
}
```

## 🎮 玩法流程

1. **获取内丹**：通过任务/副本/商城获得内丹
2. **升级内丹**：吞噬相同内丹或使用经验书
3. **装备内丹**：在宠物界面装备到对应槽位
4. **享受效果**：战斗中获得属性加成和特殊效果
5. **卸下内丹**：可以卸下重新装备其他内丹
