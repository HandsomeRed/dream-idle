# v0.94 阵法系统 (Formation System)

## 📋 概述

阵法系统是梦幻西游经典玩法之一，玩家可以通过布置阵法来获得战斗中的属性加成和战术优势。

## 🎯 核心功能

### 1. 阵法类型
- **天覆阵**：全员速度 +15%，伤害 -5%
- **地载阵**：全员防御 +20%，速度 -10%
- **风扬阵**：全员伤害 +15%，防御 -10%
- **云垂阵**：全员灵力 +20%，速度 -5%
- **鸟翔阵**：全员速度 +25%，防御 -15%
- **蛇蟠阵**：全员封印命中 +20%，抗封 -10%
- **虎翼阵**：全员伤害 +20%，速度 -10%
- **龙飞阵**：全员灵力 +25%，防御 -10%
- **雷绝阵**：全员暴击 +15%，抗暴 -10%

### 2. 阵法获取
- 剧情任务奖励
- 帮派技能学习
- 副本掉落
- 商城购买

### 3. 阵法升级
- 阵法经验提升阵法等级
- 每级提升 2% 基础效果
- 最高等级：20 级

### 4. 阵法位置
- 5 个位置：队长位 +4 队员位
- 不同位置有不同加成系数
- 队长位：100% 效果
- 2 号位：80% 效果
- 3-5 号位：60% 效果

### 5. 阵法克制
- 阵法之间存在克制关系
- 克制方：伤害 +25%
- 被克制方：伤害 -25%
- 平局：无影响

## 📊 数据结构

```typescript
interface Formation {
  id: string;
  name: string;
  description: string;
  level: number; // 1-20
  exp: number;
  bonuses: FormationBonus[];
}

interface FormationBonus {
  position: number; // 1-5
  stat: StatType;
  value: number; // percentage
}

interface FormationMatchup {
  strongAgainst: string[]; // 克制的阵法
  weakAgainst: string[]; // 被克制的阵法
}
```

## 🎮 玩法流程

1. **学习阵法**：通过任务/帮派/商城获取阵法秘籍
2. **布置阵法**：战斗中队长选择阵法和位置
3. **享受加成**：根据阵法获得属性加成
4. **升级阵法**：使用阵法经验书或战斗积累
